기준: We edit는 **GPL-3.0-or-later**. 허용: MIT / BSD / Apache-2.0 / ISC / LGPL / GPL-3.0(이상). **불가**: GPL-2.0 전용, 비상업(CC BY-NC 등), 연구 전용 라이선스. 모델 **가중치 라이선스는 코드와 따로** 확인.
"상태"가 `확인 필요`인 것은 **쓰기 전에 직접 라이선스 파일을 읽는다.** 이 표의 라이선스는 조사 시점에 저장소 소개글·검색 결과로 본 것이며, 반입·배포 전에 해당 `LICENSE` 파일로 재확인한다.
