# SPEC-06 화면 · 작업 흐름: 내보내기 · 작업 영역 · 멀티카메라 · 내 효과 프리셋 · 기본 사운드 패널

## 0. 현재 상태 (코드로 확인)
- 작업 영역(Workspace)은 `op-ui/src/workspace.rs`의 열거형이고 메뉴로 전환한다(`app/mod.rs`: 현재 값 `config/workspaces/current.txt`, 값마다 레이아웃 파일 `editing.v9.json` 등). **화면 위쪽의 탭 줄은 없다**(구현 전 메뉴 구조를 다시 확인).
- `op-core/src/presets.rs`의 프리셋은 **내장 애니메이션 프리셋**(확대·페이드·슬라이드·회전·블러·흔들림·룩)이다. **사용자가 만든 효과 묶음을 저장하는 기능은 없다.** 다른 클립에 효과를 복사·붙여넣기(여러 클립 동시)는 구현돼 있다(`effects_clipboard.rs`).
- 멀티카메라 관련 코드 없음. 클립 소리 동기화는 있음(`clipsync.rs`, `audio_sync.rs`).
- 패널 목록은 `workspace.rs`의 `Panel::ALL`(현재 24개: 기본 사운드, 내보내기 대기열 포함).
- 기본 사운드 패널(`essential_sound.rs`)은 현재 **음악 리믹스**만 한다.

## 2. U1 내보내기 (상세는 `09-접수된-문제와-수정지시.md`)
- **B-01** "화면 끄기" 체크가 모든 내보내기 경로에서 지켜지고, 켜져 있으면 모니터에 그림 없이 **진행 카드만**. 체크 방향은 사용자 말대로(`화면 끄기` 기본 체크). 스크린샷 증거와 합격 기준은 `09` 참조.
- **B-04** 내보내기는 `이름.mp4.part`로 쓰고 **성공했을 때만 최종 이름으로 바꾼다**(`moov` 없는 깨진 파일이 남지 않게).
- **B-03** 내보내기·자동 저장·캐시 드라이브 **여유 공간 경고**.
- 진행 카드 문구(안): `내보내는 중 · 48 % · 남은 시간 7분 20초 · 52 fps` + 단계(마스터링을 켰으면 `소리 분석 → 마스터링 → 영상`), `일시정지` / `취소` 버튼. 취소는 즉시 반응하고 임시 파일을 지운다.
- 내보내기가 끝나면: 상태줄 + (설정에서 켜면) 소리 알림, `폴더 열기` 버튼.

## 3. U2 작업 영역 탭 줄
- 메뉴 줄 아래(또는 위)에 **작업 영역 이름 탭**(예: 어셈블리·편집·색상·효과·오디오·그래픽 등 `Workspace` 열거 값 그대로)을 한 줄로 표시, 클릭하면 전환(지금 메뉴와 같은 동작). 현재 탭 강조. 우클릭: `이 작업 영역 초기화`, `새 작업 영역으로 저장…`(사용자 이름), `삭제`(내장 제외).
- 사용자 정의 작업 영역 저장 형식: `config/workspaces/user-<이름>.json`(기존 레이아웃 JSON 그대로).
- 시험: 탭 클릭 = `Workspace` 전환, 앱 재시작 후 마지막 작업 영역 유지, 초기화가 기본 레이아웃으로 복원, 버튼 스윕 시험(`test_v3_button_sweep`류 UI 전수 클릭이 아니라 이 프로젝트의 UI 시험 방식)에 포함.

## 4. U3 내 효과 프리셋
- **저장**: 클립 우클릭 → `효과를 프리셋으로 저장…` — 선택 클립의 효과 목록(고정 효과 모션·불투명도 포함 선택 가능)을 이름과 함께 `config/presets/<이름>.wedpreset`(JSON: 효과 id, 값, 키프레임은 **클립 시작/끝 기준 상대 시간**)로 저장.
- **적용**: 효과 패널의 새 분류 `내 프리셋`에서 드래그 또는 더블클릭, 여러 클립 선택 후 적용 가능(`effects_clipboard.rs`의 여러 클립 처리 재사용), 한 번의 되돌리기.
- **관리**: 이름 바꾸기·삭제·내보내기/가져오기(파일 공유).
- 시험: 저장 → 다른 클립에 적용 → 값·키프레임 위치(길이가 다른 클립에서도 상대 위치) 동일, 여러 클립 동시 적용, 되돌리기 한 번, 존재하지 않는 효과 id가 든 프리셋은 건너뛰고 알림.

## 5. U4 기본 사운드 패널 확장
`essential_sound.rs`(현재 리믹스만)에 구역을 추가:
1. **역할**(대화/음악/효과음/주변음) 선택과 `자동 보정` — `02`의 A8.
2. **대화 위에서 음악 줄이기** — `02`의 A7.
3. **소리 크기 맞추기** — `02`의 A5 바로가기.
4. **마스터링** 진입 — `01`의 `마스터링` 패널 열기 버튼과 현재 계획 요약(`목표 −14 LUFS · 말+음악 · 저장됨`).
- 선택 클립이 없으면 각 구역은 이유와 함께 비활성(예: "타임라인에서 오디오 클립을 선택하세요")으로 보이고, 눌러도 반응 없는 버튼은 없어야 한다(`00` 규칙 5).
- 시험: 각 구역의 비활성 문구·활성 조건(헤드리스 egui 시험 — 2026-10-14 구현된 `layout_tests` 패턴), 적용 시 되돌리기 한 번.

## 6. U5 멀티카메라 (요청이 있을 때)
1. **멀티카메라 시퀀스 만들기**: 같은 장면을 찍은 2~4개 클립(서로 다른 카메라·마이크) 선택 → `clipsync.rs`의 소리 동기화로 오프셋 계산 → 중첩 시퀀스 `멀티카메라 N` 생성(각 앵글이 비디오 트랙 1개, 소리는 선택한 앵글 또는 별도 마이크).
2. **멀티카메라 모니터** `Panel::Multicam`: 앵글을 2×2(또는 1+3)로 동시에 보여 주고(각 앵글의 현재 프레임, 디코더는 `05`의 P1 레인 사용), 재생 중 숫자키 1~4로 앵글 전환.
3. **녹화 편집**: 전환 순간마다 대상 시퀀스에 클립 조각을 자른다. 각 조각은 `Clip.multicam_angle: Option<u8>`(`serde(default)`)를 가지며 `plan.rs`가 중첩 시퀀스의 **선택된 앵글 트랙만** 평가한다.
4. **사후 수정**: 컷 우클릭 `앵글 바꾸기`.
- 시험: 동기 오프셋 정확도(합성 박수 소리 ±1프레임), 앵글 지정 클립의 렌더가 해당 앵글 트랙만 사용, 전환 녹화가 면도날 컷으로 남고 되돌리기 한 번, 옛 프로젝트 호환.
- 규모가 크므로 착수 전에 사용자에게 실제로 필요한지 확인한다(사용자 영상은 한 카메라 + 화면 녹화).

## 7. U6 색·분위기
사용자가 "프리미어처럼 색이 강하고 시원하게" 요청해 2026-10-14에 팔레트를 바꿨다. **사용자 판단 대기**: 마음에 들지 않으면 `theme.rs`의 `ACCENT`/배경/클립 색 값만 조정하는 작은 작업으로 처리(스크린샷 비교 → 수치 조정).
