# SPEC-02 오디오: 음성 정리 · 소리 크기 · 자동 덕킹 · 역할별 보정

소리 처리 3층 중 **1층(클립 정리)과 2층(믹스)** 을 맡습니다. 3층(전체 마스터)은 `01`(AudioMaster)입니다. 사용자의 작업은 **말 위주 + 배경음 + 효과음**이므로 이 문서의 항목이 마스터링 품질을 좌우합니다(소음이 있는 목소리는 마스터링으로 고쳐지지 않음).

## 0. 현재 상태 (2026-10-14 코드에서 확인)
- 소리 효과 27종: amplify, autopan, bandpass, bass, bitcrusher, chorus, **compressor**(threshold·ratio·attack·release·output·auto_gain, 니 없음), delay, distortion, fill_left/right, **hard_limiter**(ceiling·input·lookahead·release), highpass, invert, lowpass, **noise_gate**, notch, **parametric_eq**(저음 선반+밴드+고음 선반, 16개 값), phaser, pitch_shifter, radio_voice, reverb, simple_eq, stereo_expander, swap_channels, treble, tremolo.
- DSP 블록(`op-audio/src/dsp.rs`): `Biquad`(LowShelf/HighShelf/HighPass/…/Notch), `Delay`, `Compressor`, `Limiter`, `Reverb`, `Modulation`, `Lfo`, `Phaser`, `Crusher`, `Gate`, `PitchShifter`. 효과 처리는 `effects.rs`의 `process(state, fx, buf, channels, rate)`(인터리브 블록), 상태는 `FxState` 열거형.
- **없는 것**: 잡음 제거, 험 제거, 치찰음 제거, 소리 크기 측정·맞추기, 실시간 소리 크기 미터, 자동 덕킹, 역할별 자동 보정.
- 볼륨 선(키프레임): 오디오 클립의 `catalog::VOLUME`의 `level` 파라미터(`timeline.rs`의 `volume_*`), 점 추가·이동·삭제 가능(2026-10-14 구현).
- 이미 있는 분석 부품: `op-silence`(earshot 신경망 음성 감지 `Method::Neural`), `op-speech`, `op-remix`. 소리 크기 분석은 **`01`에서 반입하는 `op-master::analyze`** 를 재사용한다(LUFS 코드를 또 만들지 않는다).

## 2. A1 음성 잡음 제거 `op.audio.denoise`
- **크레이트**: `nnnoiseless`(RNNoise의 Rust 판, BSD-3-Clause, 0.5.2). 내장 모델이라 파일을 따로 받지 않는다. **구현 전에 docs.rs에서 확인할 것**: `DenoiseState::new()`/`process_frame` 시그니처, 프레임 크기(480표본 = 48 kHz에서 10 ms), 입력 표본 크기(16비트 정수 범위의 실수일 가능성 → ±32768 배율), 모노 전용 여부.
- **카탈로그**(`op-core/src/catalog.rs`): `def!("op.audio.denoise","Noise Reduction",AudioEffect,CAT_AUDIO_NOISE?,[],DENOISE)`; 값: `amount`(0~100 %, 기본 100: 처리음·원음 섞기), `voice_only`(bool, 음성 확률이 낮은 구간은 더 줄임, 기본 꺼짐).
- **구현**(`effects.rs`/`dsp.rs`): `FxState::Denoise(Box<Denoiser>)` — 채널마다 `DenoiseState` 하나, 입출력 480표본 링 버퍼. **블록 처리 중 메모리 할당 금지**(상태에 미리 준비). 480표본(10 ms) 지연은 알려진 한계로 문서화(립싱크 허용 범위 안).
- **48 kHz 전용**: 다른 표본율이면 **원음 통과 + 효과 제어창에 한국어 안내 줄**(`48 kHz에서만 동작합니다`)과 상태줄 알림 1회. 조용히 무시하지 않는다(규칙 5).
- **시험**(`op-audio` 단위 시험): ① 사인파 말 비슷한 신호 + 흰 잡음(SNR 10 dB) → 잡음만 있는 구간 에너지 ≥ 10 dB 감소, 신호 구간 0.3~3.4 kHz 에너지 변화 ≤ 3 dB ② 256/4096 표본 블록으로 나눠 처리해도 결과 동일(차이 ≤ 1e-4) ③ `amount=0` → 입력과 동일 ④ 블록당 처리 시간이 실시간의 5 % 미만.
- **번역**: `ko.rs`·`es.rs`에 이름·분류·값 이름 모두.

## 3. A2 험 제거 `op.audio.dehum`
- 50 또는 60 Hz와 배음(최대 6개)에 좁은 노치 필터. 값: `frequency`(선택: 50/60), `harmonics`(1~6, 기본 4), `depth`(dB). 기존 `Biquad`의 Notch(Q≈30) 묶음이라 신규 DSP 최소.
- 시험: 60 Hz 험(−30 dBFS) + 말 신호 → 60·120·180 Hz 성분 ≥ 20 dB 감소, 1 kHz 변화 ≤ 0.2 dB.

## 4. A3 치찰음 제거 `op.audio.deesser`
- 방식: 검출용 밴드패스(기본 4.5~9 kHz, 중심 6.5 kHz) 에너지가 `threshold`를 넘으면 **그 대역만** `max_reduction`(dB, 기본 −6, 최대 −12)까지 줄인다(저·고역 분리 후 고역만 압축, 다시 합침). 값: `frequency`, `threshold`, `max_reduction`, `listen`(검출음 듣기).
- 시험: 6.5 kHz 잡음 버스트가 있는 신호 → 버스트 ≥ 6 dB 감소, 1 kHz 사인 변화 ≤ 0.3 dB, 버스트가 없으면 출력 = 입력(±0.05 dB).

## 5. A4 다이내믹스 보강
- `op.audio.compressor`에 `knee`(dB, 기본 **0 = 기존 동작 그대로**) 값 추가. 새 값은 기본값이 옛 동작과 같아야 한다(저장된 프로젝트 호환).
- 새 `op.audio.expander`(하향 익스팬더): `threshold`, `ratio`(1~4), `attack`, `release`, `range`(최대 감쇠 dB). 노이즈 게이트보다 부드럽게 작은 소리를 낮춘다.
- 시험: 니 0일 때 기존 압축 시험 결과 불변. 익스팬더: 임계값 아래 신호 `range`만큼 감쇠, 위는 불변.

## 6. A5 소리 크기 맞추기 (클립 단위)
- **메뉴**: 오디오 클립 우클릭 → `소리 크기 맞추기…`(여러 클립 선택 가능). 대화창: 목표 프리셋 `대화 −16 LUFS` / `음악 −24 LUFS` / `효과음 −20 LUFS` / 직접 입력(**시작값이며 사용자 청취로 확정**).
- **동작**: 클립이 쓰는 원본 소리의 해당 구간을 `ConformedAudio`에서 꺼내 `op_master::analyze`로 통합 LUFS 측정 → 목표와의 차이를 클립 볼륨 `level`(또는 `gain_db`)에 반영. 클립 효과는 측정에 포함하지 않는다(원본 기준, 문서에 명시). **한 번의 되돌리기 단계**.
- **한계 처리**: 측정이 −70 LUFS 미만(무음)이면 "너무 조용해서 측정할 수 없습니다" 알림. 이득 변화는 ±24 dB로 제한.
- MCP: `match_loudness {clip_ids, target_lufs}` → 클립별 적용 이득 JSON.
- 시험: 알려진 레벨(−30 LUFS 수준 변조 잡음) 클립 → 적용 후 `analyze` 결과 목표 ±0.3 LU. 다중 선택 일괄. 되돌리기 한 번에 전부 복구.

## 7. A6 실시간 소리 크기 미터 (`Panel::Loudness`, "소리 크기")
- `ebur128` 크레이트(MIT)로 M/S/I/LRA/트루피크를 계산. **재생 엔진 스레드**(`op-audio/src/engine.rs`)에서 마스터 출력 직후 표본을 `EbuR128`에 공급하고 결과를 원자 변수(`f32` 비트)로 공개 → UI가 읽기만 한다(블록 처리 중 할당 금지).
- 표시: 순간·단기·통합 LUFS, LRA, 트루피크, **목표선**(−14 등) 대비 막대. `재설정` 버튼(통합값 초기화). 재생을 멈추면 값 유지.
- 시험: −23 LUFS 기준 신호를 재생 엔진에 흘려 통합값이 −23 ± 0.3(측정 3초 이후). `op-master::analyze`와 같은 입력에서 ±0.2 LU 이내.

## 8. A7 자동 덕킹 (대화 위에서 음악 줄이기)
**목표**: 사용자가 말할 때 배경음이 자연스럽게 내려가고, 말이 끝나면 천천히 올라온다. 결과는 **볼륨 선의 점**으로 남아 사용자가 직접 고칠 수 있다(투명하고 되돌릴 수 있음).
- **입력**: 대화 트랙(들)과 음악 트랙(들) 선택(기본: 말이 많은 트랙을 자동 추정 → 사용자가 바꿈).
- **분석**: `op-silence`의 신경망 음성 감지로 대화 트랙 **믹스다운**(클립 볼륨·효과 포함, `01`의 `render_mixdown`을 트랙 한정으로 호출)에서 말 구간을 찾는다 → 0.3초 이하 틈은 이어 붙이고, 앞뒤 여유(0.15초) 추가. 백그라운드 작업(`remix.rs` 패턴: 진행·취소).
- **키프레임 생성**: 말 구간마다 음악 클립 `level`에 4점 — `시작−attack` 기준값, `시작` 기준−`duck_db`, `끝+hold` 기준−`duck_db`, `끝+hold+release` 기준값. 기본값: `duck_db = 12`, `attack = 0.25 s`, `release = 0.6 s`, `hold = 0.15 s`. 이웃한 구간이 가까우면 점을 합쳐 개수를 줄인다(최소 간격 0.2초).
- **기존 점**: 음악 클립에 이미 볼륨 점이 있으면 **"기존 볼륨 점은 지워집니다"** 확인. 한 번의 되돌리기로 복구.
- **UI**: `기본 사운드` 패널(`essential_sound.rs`)에 `대화 위에서 음악 줄이기` 구역: 대화 트랙·음악 트랙 선택, `줄이는 양`(dB), `내려가는 시간`, `올라오는 시간`, `민감도`, `적용` / `되돌리기`. 클립 우클릭 `자동 덕킹…`.
- **MCP**: `auto_duck {dialogue_tracks, music_tracks, duck_db?, attack?, release?}` → 만든 점 개수·구간 수.
- **시험**(합성): 말 구간 = 톤 버스트, 음악 = 잡음 → 적용 후 말 구간의 음악 레벨 ≤ 기준 −11 dB, 말 밖 = 기준 ±0.1 dB, 전환 시간이 설정값 ±50 ms, 점 개수가 구간 수 × 4 이하. 말이 전혀 없으면 점을 만들지 않고 알림.

## 9. A8 역할별 자동 보정 (기본 사운드 패널)
- `Clip`에 `audio_role: Option<AudioRole>`(`Dialogue/Music/Effects/Ambience`, `#[serde(default)]`). 클립 우클릭 `역할 지정` 또는 패널 선택.
- `자동 보정` = 역할별 **기존 효과 묶음**을 클립 효과로 넣고(한 번의 되돌리기) 소리 크기 맞추기(A5)를 함께 적용. 시작값(청취로 조정):
| 역할 | 효과 묶음 | 목표 |
|---|---|---|
| 대화 | 고역통과 80 Hz → 잡음 제거(강도 60 %) → 치찰음 제거 → 명료도(3 kHz +1.5 dB) → 압축 2:1 | −16 LUFS |
| 음악 | 저역 정리(고역통과 40 Hz) | −24 LUFS (덕킹과 함께) |
| 효과음 | 없음 | −20 LUFS |
| 주변음 | 고역통과 100 Hz | −30 LUFS |
- 이미 같은 효과가 있으면 중복해서 넣지 않는다. 시험: 역할 지정 → 효과 목록과 소리 크기 확인, 되돌리기 한 번에 복구, 옛 프로젝트 열림.

## 10. A9 클릭·튐 제거 (낮은 우선)
Hampel 필터로 짧은 튐(≤ 2 ms)을 주변 값으로 보간. 값: `sensitivity`. 시험: 클릭이 심어진 사인파 → 클릭 진폭 ≥ 20 dB 감소, 사인 왜곡 ≤ 0.1 %.

## 11. 공통 작업 규칙
- 새 효과는 `catalog.rs` 정의 + `effects.rs` 분기 + `ko.rs`/`es.rs` + `op-audio` 단위 시험 + `NOTICE.md`(가져온 크레이트). 효과 제어창 표시는 기존 카탈로그 자동 UI가 처리한다.
- 모든 소리 효과는 **블록 크기와 무관한 결과**, **무할당**, **NaN 방지**(`sanitize`)를 시험한다.
- 순서 제안: A5(소리 크기 맞추기)·A7(덕킹)이 사용자 체감이 가장 큼 → A1(잡음 제거) → A2·A3 → A6 → A8 → A4·A9.
