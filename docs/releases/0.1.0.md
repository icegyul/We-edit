OpenPremier 0.1.0 es la primera versión alfa pública del editor. Incluye una aplicación funcional para Windows y Linux, empaquetada y comprobada desde su distribución final.

## Descargas

- **Windows x64:** descarga el archivo ZIP, extráelo y ejecuta `OpenPremier.exe`.
- **Linux x86-64:** descarga el AppImage, dale permiso de ejecución y ábrelo normalmente.
- **SHA256SUMS.txt:** contiene las sumas SHA-256 para verificar las descargas.

## Funciones incluidas

- Timeline multipista con las operaciones principales de edición y zoom discreto con Ctrl/Cmd + rueda.
- Paneles acoplables para proyecto, monitores, timeline, controles de efectos, audio, color y scopes.
- Lectura, decodificación y exportación mediante FFmpeg.
- Composición GPU mediante wgpu.
- Formato nativo `.opproj` e intercambio OTIO, FCP XML y EDL.
- Importación parcial y de solo lectura de proyectos `.prproj`.
- Interfaz en español e inglés.

## Estado de esta versión

Esta es una versión alfa para evaluación y pruebas. Todavía no incluye OpenFX, VST3, scripting WebAssembly ni compatibilidad completa con `.prproj`. Los problemas reproducibles pueden informarse desde la sección Issues del repositorio.
