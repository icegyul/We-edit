# Security policy

## Supported versions

OpenPremier is currently a technical alpha. Security fixes target the latest commit and most
recent 0.1.x prerelease; older snapshots are not maintained.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities, malicious project/media samples, path traversal,
memory corruption, or dependency compromise. After the GitHub repository is created, enable
private vulnerability reporting under **Settings > Security > Code security and analysis**, then
use **Security > Advisories > Report a vulnerability**.

Include the affected version, platform, impact, minimal reproduction, and whether a sample can be
shared privately. Do not include customer media, credentials, or proprietary Adobe files.

The maintainers should acknowledge a report within seven days and coordinate disclosure after a
fix and packaged regression test are available.
